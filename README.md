# LocalPdfWorkbench

**ローカルPDFワークベンチ（試作）**は、PDFの結合・分割・抽出・回転・整理・トリミングを、Windows PC内で行うアプリです。入力PDFを変更せず、加工結果を別のPDFとして保存します。

Windows 11 x64に対応しています。実行ファイル1個で起動でき、.NETランタイム、Python、Adobe Acrobatの追加インストールやアカウントは不要です。PDFの読み込み・表示・加工・保存はオフラインで使え、文書のアップロードは行いません。

このリポジトリはアプリの配布用です。ソースコードは公開していません。

## ダウンロードと起動

1. [リリースページ](https://github.com/UsumebiNamekuji/LocalPdfWorkbench-releases/releases/tag/v0.1.0)から [LocalPdfWorkbench.exe](https://github.com/UsumebiNamekuji/LocalPdfWorkbench-releases/releases/download/v0.1.0/LocalPdfWorkbench.exe) をダウンロードします。
2. 任意のフォルダーに置き、`LocalPdfWorkbench.exe` をダブルクリックします。インストールや管理者権限は不要です。
3. 「PDFを追加」、またはエクスプローラーからのドラッグ＆ドロップでPDFを追加します。
4. 加工後は、画面下部でファイル名・対象ページ・保存方法を確認し、保存先を選んで保存します。

## できること

| 機能 | 操作 |
|---|---|
| 結合 | 複数のPDFを追加し、ファイル単位で順序を変更します。 |
| 整理 | ページを並べ替え、不要なページを作業一覧から除外します。 |
| 回転 | 選択したページを左右に90度回転します。 |
| トリミング | 拡大表示で残す領域を指定し、現在・選択・全ページに適用します。 |
| 分割 | ページ間の区切り、連続範囲、Nページごと、1ページずつで分けます。 |
| 抽出 | 選んだページをまとめて1ファイル、または1ページずつ保存します。 |

ページの順序、除外、適用済みの回転・トリミングは各機能で共有します。「分割」「抽出」を開くと保存方法が切り替わり、他の機能へ移ってもその保存方法が続きます。画面下部で「全ページを1つに」へ戻せます。

範囲の文字列は「反映」またはEnterで確定してください。未適用のトリミングも、適用するか指定を取り消してから保存します。`6 / 8ページは出力対象外` は、現在の一覧8ページのうち6ページを今回保存しないという意味です。

取り消し・やり直しに対応しています。「作業を複製」で編集状態を引き継いだ別タブを作り、独立して編集できます。保存後も作業一覧と設定は残ります。

## パスワード

パスワード付きPDFの読み込みと、出力PDFのパスワード保護に対応しています。保護付き入力を使う出力は、初期設定で保護を求めます。必要に応じて新しい出力用パスワードを指定するか、「保護せず保存」を明示的に選べます。

出力用パスワードは**1～32文字の半角英数字・記号（半角スペース可）**です。入力PDFを開くパスワードには、この制限を適用しません。元の印刷・コピーなどの権限制限は引き継ぎません。

## 試作版の制約

- トリミングは表示・印刷する範囲の調整です。範囲外の内容の完全除去や墨消しには使えません。
- 署名・フォーム・注釈・リンク・しおりなどの完全な維持は保証しません。既存の電子署名は加工後の有効性を維持できません。保存後のPDFを確認してください。
- 2GB以上のPDFは読み込めません。大きなPDFを多数追加すると、多くのメモリを使います。
- 作業状態の保持はアプリの起動中のみです。終了後の復元やプロジェクト保存には対応していません。
- OCR、圧縮、形式変換、PDF内の文字編集などには対応していません。

アプリ内の「使い方・ライセンス」で、基本操作と第三者コンポーネントのライセンス表示を確認できます。
